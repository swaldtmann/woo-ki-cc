# woo-ki-cc — Autoren

Texte, Beispiele und Hooks dieses Repos sind in Zusammenarbeit zwischen Stephan Waldtmann und Claude Code entstanden.

## Konzept und Pflege

- **Stephan Waldtmann** — Konzept, Auswahl der Prinzipien, Erfahrungs-Basis aus täglicher Praxis, redaktionelle Verantwortung.
  Website: https://waldtmann.de · Codeberg: https://codeberg.org/StephanWaldtmann

## Co-Autorschaft

- **Claude Code (Anthropic)** — Modell-gestütztes Schreiben der Texte, Beispiele und Hooks. Genutzte Modelle überwiegend Claude Opus 4.7 und Sonnet 4.6. Jede Änderung wurde von Stephan geprüft, bevor sie eingecheckt wurde — Verantwortung für den Inhalt liegt bei Stephan, die Formulierungs- und Beispiel-Arbeit ist gemeinschaftlich.

Commits, die überwiegend modell-erstellt sind, tragen einen `Co-Authored-By:`-Trailer mit Claude-Modell-Angabe (siehe `CONTRIBUTING.md` → "Commit-Konvention").

## Inspiration

- **Forrest Chang** — hat Karpathys Einsichten in eine CLAUDE.md-Datei gegossen (>100k Sterne auf GitHub, Mai 2026): https://github.com/forrestchang/andrej-karpathy-skills
- Die vier Reflexe in unserer `CLAUDE.md` folgen dieser Tradition, sind aber neu formuliert (deutsch, du-Form, mit [`woo-ki-starter`](https://codeberg.org/StephanWaldtmann/woo-ki-starter)-Workflows verzahnt).
